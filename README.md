## 收录规则

- **必装**：新系统安装后优先恢复。
- **按需安装**：已验证实用，需要时再安装。
- **待体验 / 待整理**：暂未确定是否正式收录，或仍需整理使用记录。
- 各软件保留用途、官网、GitHub 和我的使用体验；无链接填写 `-`。
- **我的使用体验**由本人填写；简评放在表格中，详细记录可使用折叠区。
