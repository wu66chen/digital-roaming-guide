## 收录规则

- **必装**：新系统安装后优先恢复。
- **按需**：已经验证好用，需要时再安装。
- **待体验**：尚未确定是否值得长期保留，记录在 `INBOX.md`。
- 每款软件保留**用途、官网、GitHub、我的使用体验**字段；没有对应链接时写 `-`。
- “我的使用体验”由本人填写，不预先生成个人评价。
