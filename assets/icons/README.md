# 图标来源

- `apple.svg`：Apple 品牌图形，来源：[Font Awesome Free — Apple](https://fontawesome.com/icons/apple?f=brands&s=solid)。
- `windows.svg`：Windows 品牌图形，来源：[Font Awesome Free — Windows](https://fontawesome.com/icons/windows?f=brands&s=solid)。

图标使用 Font Awesome Free 6.7.2 的原始矢量路径，仅调整填充颜色以兼容 GitHub 深色与浅色主题。
