## 新系统必装

### 1. 图形界面软件（GUI）

| 软件 | 用途 | 官网 | GitHub | 我的使用体验 |
| --- | --- | --- | --- | --- |
| **Pastel** | 查找及下载 iOS App 历史版本 IPA，并传输到 iPhone / iPad | - | [GitHub](https://github.com/EEliberto/Pastel-macOS) | *待填写* |
| **wifi-loc-control** | 依据已连接的 Wi-Fi 自动切换 macOS 网络位置 | - | [GitHub](https://github.com/vborodulin/wifi-loc-control) | *待填写* |
| **NewFile** | 为 Finder 添加右键或工具栏中的“新建文件”操作 | [官网](https://newfile.dev/) | [GitHub](https://github.com/mariusgm/newfile) | *待填写* |
| **AppCleaner** | 卸载 App 并查找相关配置与残留文件 | [官网](https://freemacsoft.net/appcleaner/) | - | *待填写* |
| **PureMac** | 通过图形界面进行存储分析、缓存清理和应用管理 | - | [GitHub](https://github.com/momenbasel/PureMac) | *待填写* |
| **Mole（CLI）** | 使用终端命令进行应用卸载、磁盘分析及清理 | - | [GitHub](https://github.com/tw93/Mole) | *待填写* |
| **Mos** | 调整外接鼠标的滚轮平滑效果和滚动方向 | [官网](https://mos.caldis.me/) | [GitHub](https://github.com/Caldis/Mos) | *待填写* |


### 2. 命令行工具（CLI）

| 软件 | 用途 | 官网 | GitHub | 我的使用体验 |
|---|---|---|---|---|
| **Homebrew** | macOS 软件与命令行包管理器，支持软件安装、更新及卸载 | [官网](https://brew.sh/) | [GitHub](https://github.com/Homebrew/brew) | *待填写* |
