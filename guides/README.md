## 记录约定

- 标题写问题或目标，避免「技巧分享」「一些经验」等模糊词。
- 优先写最安全、最省步骤的办法；可选方案放在后面。
- 步骤明确操作对象、路径、命令和预期结果。
- 涉及删除、系统安全、网络或权限修改时，提供风险及恢复办法。
- 尚未亲自验证的内容，标记「待验证」；不要写成已解决。
