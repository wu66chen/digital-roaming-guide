## 三款工具的区别

| | AppCleaner | PureMac | Mole（CLI） |
| --- | --- | --- | --- |
| **主要用途** | 应用卸载、关联残留 | 图形化综合清理、磁盘与应用管理 | 终端清理、磁盘分析、卸载 |
| **适合** | 只想卸载某个 App | 想用图形界面查看和选择清理内容 | 习惯命令行、需要更细的控制 |
| **优点** | 操作简单、聚焦 | 功能集中、直观 | 覆盖面广、便于组合命令 |
| **不足** | 不提供完整磁盘维护功能 | 与另两款功能重叠 | 需要了解命令和清理路径 |
| **官网** | [官网](https://freemacsoft.net/appcleaner/) | - | - |
| **GitHub** | - | [项目](https://github.com/momenbasel/PureMac) | [项目](https://github.com/tw93/Mole) |

## 使用建议

- **卸载单个 App**：优先使用 AppCleaner。
- **检查磁盘占用、图形化选择清理内容**：使用 PureMac。
- **处理开发缓存、复杂目录分析或终端任务**：使用 Mole CLI。

涉及文件删除时，先确认候选路径和清理范围。Mole 的开源 CLI 与另行提供的图形版应当区分。
