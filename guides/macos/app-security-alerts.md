# macOS｜允许“任何来源”的应用程序

安装软件后，如果出现“XXX 已损坏”“无法验证开发者”等提示，在确认软件来源可信后，可以尝试以下操作。

### 1. 终端执行命令

打开「终端」，输入以下命令并回车：

```bash
sudo spctl --master-disable
```

根据提示输入 **Mac 登录密码**。

### 2. 开启“任何来源”

打开系统设置，依次进入：

**系统设置 → 隐私与安全性 → 安全性**

在「允许以下来源的应用程序」中选择 **「任何来源」**，输入登录密码并确认。

### 3. 重新打开应用

设置完成后，尝试**重新打开应用程序**。

> [!CAUTION]
> 此操作会降低系统安全性，仅用于可信软件。部分新版 macOS 可能不支持该命令或不显示「任何来源」选项。若系统明确检测到恶意软件，请勿绕过安全检查。
