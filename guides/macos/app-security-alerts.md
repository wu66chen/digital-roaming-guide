# macOS｜允许“任何来源”的应用程序

安装软件后，如果出现“XXX 已损坏”“无法验证开发者”等提示，可以尝试开启允许“任何来源”的应用程序运行。

**操作步骤：**

1. 打开「终端」，输入以下命令并回车：

   ```bash
   sudo spctl --master-disable
   ```

   根据提示输入 Mac 登录密码。

2. 打开「系统设置」→「隐私与安全性」，向下找到「安全性」→「允许以下来源的应用程序」，选择「任何来源」，输入登录密码并确认。

3. 设置完成后，重新打开应用程序即可。

**注意：** 此操作会降低系统安全性，仅建议用于来源可信的软件。部分新版 macOS 可能不支持此命令或不显示「任何来源」选项。如果系统明确提示检测到恶意软件，请勿直接绕过安全检查。
