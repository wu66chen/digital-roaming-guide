# 软件条目模板

[返回首页](../README.md)

复制到对应的 `catalog/*.md` 文件中：

```markdown
### 软件名称

- **用途**：一句话说明具体作用。
- **官网**：- 
- **GitHub**：-
- **我的使用体验**：_待填写_
```

有官网或 GitHub 就替换 `-` 为真实链接，例如 `[访问](https://example.com)`；没有则保留 `-`。

对于用户脚本或商店扩展，可以额外加：

```markdown
- **Greasy Fork / 应用商店**：[安装](https://example.com)
```

分类按实际使用情况写在对应的“新系统必装”“按需安装”或“待体验”区域。
